### 跨平台內容策略矩陣

| 平台 | 內容定位 | 頻率 | 主要格式 | 成功指標 |
|------|---------|------|---------|---------|
| **LinkedIn** | 專業思想領導力 | 每週 3~5 篇 | 文字+圖表 | 互動率 ≥ 3%，粉絲月增 5% |
| **Instagram** | 品牌視覺敘事 | 每週 4~7 篇 | Reels/Story | 觸及率，保存率 |
| **TikTok** | 短影音病毒傳播 | 每天 1~2 篇 | 豎屏影片 | 完播率 ≥ 50%，分享率 |
| **小紅書** | 生活風格+場景植入 | 每週 3~5 篇 | 圖文/短影音 | 互動率 ≥ 5%，收藏率 ≥ 8% |
| **YouTube** | 深度品牌內容 | 每週 1~2 篇 | 長影片/Shorts | 完播率，訂閱轉換 |
| **Podcast** | 行業思考/品牌IP | 每週/每兩週 | 音頻 | 下載量，回頭率 |

### 內容混合比例（Content Mix）

```
品牌形象類（Branding）：  40%
  → 品牌故事、價值觀傳遞、幕後花絮

教育/價值類（Education）：40%
  → How-to、行業洞察、工具使用技巧

商業轉換類（Conversion）：20%
  → 產品展示、客戶案例、CTA

原則：不要反過來——轉換內容占超 30% 會讓受眾逃跑
```

### 小紅書策略（繁體市場台灣用戶適配版）

```
發文時機：週一~五 20:00~22:00（下班後瀏覽高峰）
                 週末 12:00~14:00（午休時段）

內容風格：
  ✓ 70% 生活風格/情境 → 展示使用場景，不是功能
  ✓ 20% 趨勢參與 → 搭上當週熱點
  ✓ 10% 品牌直球 → 產品推薦/案例

圖文構圖：
  → 封面圖第一視覺：大字+高對比（手機滑過 0.3 秒決定是否停留）
  → 9:16 豎版優先，或 1:1 方形

關鍵字策略：
  → 每篇 5~8 個 hashtag：2 大流量詞 + 3 品牌詞 + 2 長尾精準詞
```

### 品牌一致性 3 個核心守則

```
1. 品牌聲音（Brand Voice）
   → 任何平台的文案，去掉 Logo，受眾還認得出是我們嗎？
   → AI Token King 聲音：專業但不冷漠、科技但有溫度

2. 視覺系統
   → 主色/輔色/字體 → 任何素材不得跳脫（連結 Visual Style Guide）
   → 所有封面圖必須可識別為同品牌

3. 訊息一致性
   → 每季選定 1~2 個主要訊息主軸，所有平台圍繞此主軸放射
   → 不同平台是「不同包裝」，不是「不同訊息」
```
