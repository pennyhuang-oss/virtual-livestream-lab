# /find-vgf-app — 評估虛擬女友 APP 適配性

由 Hanburger 執行，評估市場上的虛擬女友 APP 是否適合直播間場景。

## 評估標準

| 項目 | 說明 | 權重 |
|------|------|------|
| 畫面可投影 | APP 能否透過 OBS 捕捉畫面（無 DRM 限制） | 高 |
| 互動自然度 | 語音/文字互動是否流暢自然 | 高 |
| 角色可客製化 | 能否調整外觀、聲音、個性 | 中 |
| 平台合規 | 內容是否符合 TikTok 直播規範 | 高 |
| 費用結構 | 免費/付費方案，試用期長度 | 中 |
| 穩定性 | 長時間直播不閃退 | 高 |

## 輸出格式

```markdown
## APP 名稱
- 平台：iOS / Android / Web
- 可投影：是/否（說明原因）
- 互動方式：語音 / 文字 / 混合
- 客製化程度：高/中/低
- 合規風險：無/低/中/高
- 費用：免費試用 X 天 / 月費 USD XX
- 推薦指數：⭐⭐⭐⭐⭐
- 備註：
```
