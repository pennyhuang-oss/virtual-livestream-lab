# /stream-checklist — 直播前設備檢查清單

由謝景行把關，Penny 最終確認。

## OBS 設定

```
□ Scene 設定：APP 畫面 (9:16) + 麥克風
□ 輸出設定：1080p / 30fps / CBR 6000kbps
□ 音頻設定：麥克風電平 -12dB ~ -6dB，APP 音效靜音（視腳本決定）
□ 虛擬攝影機已啟用（若需要）
□ 錄影備份已開啟
```

## TikTok Live Studio 設定

```
□ 帳號已登入
□ 推流金鑰已更新（每次直播需重新取得）
□ 直播標題已設定（含關鍵字）
□ 封面圖已上傳
□ 直播類別已選擇
□ 過濾詞已設定（謝景行審核）
```

## 虛擬女友 APP 設定

```
□ APP 已開啟，角色已載入
□ 投影畫面已被 OBS 捕捉
□ 聲音輸出確認（走電腦音效 or 靜音+人聲）
□ 長時間穩定測試（至少 10 分鐘無閃退）
```

## 網路與備用方案

```
□ 有線網路優先，上傳 ≥ 10Mbps
□ 手機熱點備用已準備
□ 斷線應對話術：「稍等，我去幫你拿一個東西…」
□ APP 閃退應對：螢幕切至預備畫面
```
