# 🎙️ Virtual Livestream Lab

> AI 虛擬人直播間 — 從虛擬女友 APP 測試出發，打造可因應各類客戶需求的直播間解決方案

## 專案目標

以「虛擬女友 APP 直播間」為首個測試場景，用 OBS + TikTok Live Studio 搭建直播投影環境，
驗證 AI 虛擬人直播的可行性，再逐步擴展至帶貨、教學、娛樂等多種直播類型。
